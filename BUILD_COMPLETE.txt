BUILD DATE: 2026-04-08

TECH STACK:
-----------
Frontend: React 18 + Vite + Tailwind CSS v4 + React Router + Axios + Lucide Icons
Backend:  Node.js + Express + SQLite (better-sqlite3)
Auth:     JWT (jsonwebtoken + bcryptjs)
Process:  PM2 ready (ecosystem.config.js included)

STRUCTURE:
----------
/frontend   - React Vite SPA (port 5173 dev, built to dist/)
/backend    - Express REST API (port 4050)

FEATURES BUILT:
---------------
1. USER ACCOUNTS
   - Signup with name, email, password
   - Login with JWT authentication
   - Protected routes, auto-redirect
   - User profile/dashboard

2. USER FUNDING (WALLET)
   - Mock deposit/withdraw flow (demo, no real payments)
   - Preset quick-fill amounts ($100 - $50,000)
   - Transaction history with timestamps
   - Real-time balance display in header

3. FUTURES TRADING
   - 4 contracts: BTC-FUT, ETH-FUT, GOLD-FUT, OIL-FUT
   - Buy Long / Sell Short with 10x leverage
   - Live P&L tracking on open positions
   - Close positions with realized P&L
   - Trade history (open + closed)

4. FOREX TRADING
   - 6 major pairs: EUR/USD, GBP/USD, USD/JPY, AUD/USD, USD/CHF, USD/CAD
   - Mock live rates updating every 10 seconds
   - Lot-based trading (1 lot = 100K units)
   - Color-coded price direction indicators
   - Open/close positions with P&L

5. CRYPTO INVESTING
   - 4 coins: BTC, ETH, SOL, ADA
   - Buy with USD / Sell holdings
   - Portfolio view with average price, current value, P&L %
   - Real-time price updates every 10s

6. ALGORITHMIC TRADING BOTS
   - 3 preset strategies:
     * Momentum (Medium Risk) - buys on rises, sells on drops
     * Mean Reversion (Low Risk) - buys dips, sells spikes vs average
     * Breakout (High Risk) - rides price breakouts aggressively
   - Create bots for any crypto symbol
   - Activate/deactivate toggle
   - Bots auto-trade every 30 seconds when active
   - Per-bot trade history and P&L tracking

7. REFERRAL REWARDS
   - Each user gets a unique referral code
   - Share code with friends
   - Earn 5% bonus on referred user's first deposit
   - Referral stats dashboard (total referrals, total bonus)

8. ADMIN PANEL
   - URL: /admin (login: admin@fintech.com / Admin2026!)
   - Overview dashboard with platform stats
   - View all users with balances
   - View all trades across platform
   - View all bots and their activity
   - Role-based access control

DESIGN:
-------
- Dark professional theme: #0A0F1E background, #00D4AA accent
- Clean financial dashboard aesthetic (Binance/Robinhood inspired)
- Responsive mobile-friendly with collapsible sidebar
- Color-coded P&L (green positive, red negative)
- Custom scrollbars and smooth transitions

API ENDPOINTS:
--------------
POST /api/auth/signup        - Register new user
POST /api/auth/login         - Login
GET  /api/auth/me            - Get current user

POST /api/wallet/deposit     - Add funds
POST /api/wallet/withdraw    - Withdraw funds
GET  /api/wallet/balance     - Get balance
GET  /api/wallet/transactions - Transaction history

GET  /api/trading/prices/futures  - Futures prices
GET  /api/trading/prices/forex    - Forex prices
GET  /api/trading/prices/crypto   - Crypto prices
POST /api/trading/open            - Open trade
POST /api/trading/close/:id       - Close trade
GET  /api/trading/trades          - Get trades
POST /api/trading/crypto/buy      - Buy crypto
POST /api/trading/crypto/sell     - Sell crypto
GET  /api/trading/portfolio       - Portfolio holdings

GET  /api/bots/strategies    - List strategies
GET  /api/bots               - List user bots
POST /api/bots/create        - Create bot
POST /api/bots/:id/toggle    - Toggle bot
DELETE /api/bots/:id         - Delete bot
GET  /api/bots/:id/trades    - Bot trade history

GET  /api/referrals/code     - Get referral code
GET  /api/referrals/stats    - Referral stats

GET  /api/admin/stats        - Platform stats (admin)
GET  /api/admin/users        - All users (admin)
GET  /api/admin/trades       - All trades (admin)
GET  /api/admin/bots         - All bots (admin)
GET  /api/admin/transactions - All transactions (admin)

HOW TO RUN:
-----------
# Backend
cd backend && npm install && node server.js

# Frontend (dev)
cd frontend && npm install && npm run dev

# Frontend (prod build)
cd frontend && npm run build
# Then backend serves static files from frontend/dist

# PM2 (production)
cd backend && pm2 start ecosystem.config.js
